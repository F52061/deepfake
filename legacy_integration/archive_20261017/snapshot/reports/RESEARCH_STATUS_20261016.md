## 2. 从结构到训练：当前实际上发生了什么

ViT 的 768 维 CLS 经新投影，CLIP 的 1024 维 CLS 经另一新投影，桥读取三层中间 patch 特征，最终拼接为 `[CLIP 768, Bridge 128, ViT 768]`，线性输出两类。

`train_bridge_phase1.py` 明确冻结 ViT 和 CLIP 骨干；可训练部分是投影、桥、融合头及尺度参数。`load_vit_backbone()` 明确跳过 `model.head.weight/bias`。因此它保留了改进 ViT 的骨干，却**没有保留独立 ViT 的完整检测函数**。新的投影和头可能比原生头更差。

服务器本次独立核对：融合权重的 **162/162 个 ViT 骨干张量**与 PDI `net_050.pth` 完全相同，缺失 0、不同 0；原生头的形状为 `[2,768]` 与 `[2]`。这复核了旧 G13 的权重事实，**没有证明它就是 `acc.txt` 每一行对应的 checkpoint**，也没有补齐 PDI 训练划分。

冻结 V 只意味着 V 不再适应；只要 C 含可泛化的补充，`f(V,C)` 并不被某个既有 V 分类头的成绩限制。真正要区分的是：原生头是否被保住、C 是否有补救机会、融合能否识别机会、训练是否只学源域捷径。

历史“CLIP 决策能量 62.3%”来自分类权重分段范数，不能直接等同于实际逐样本贡献、梯度份额或因果责任。标量缩放与后续线性权重还可以相互抵消，故单看 alpha 不足以判断是否充分利用分支。

## 3. 本次确认的实现故障

### 3.1 已知：`LayerNorm(1)` 抹去图像内容

对每个 token 的单一标量归一化，结果恒为 beta；前面的图像梯度为零。尾部 reduction 仍可收到来自常数的梯度，不能说桥的所有参数都没梯度。旧 LN 还掩盖了下述两个问题。

### 3.2 新确认：注意力沿 batch 做交互

外部把 `combined` 变为 `[S,B,64]`；MHA 和项目 shim 的契约是 `[B,S,64]`。因此实际在同一 token 位置的不同图片间做注意力。batch=1 时，该注意力没有跨 token 聚合；batch>1 时，同图表示会依赖同批其他图。

### 3.3 新确认：投影后的展平混排图片

`[S,B,64] -> Linear(64,1) -> view(B,S)` 未先转为 batch-first，输出每行会包含不同图片的 token 标量。仅修注意力仍无法恢复样本隔离。

候选修复在 `diagnostics/bridge_layout_candidate.py`：MHA 前转 `[B,S,D]`、返回后恢复原接口；投影前转 batch-first；移除标量 LN。只在调用进程中修改模型，保留已有 Linear 参数及 dtype。**它改变了模型函数，旧桥权重不能视为正确桥的训练结果，须重新训练。**

服务器隔离检查使用实际源文件提取的小模块、固定随机输入、三阶段链，全部断言通过：

| 单个注意力块：样本0输出最大差 | 2.088730 | 0 |
| 样本0输出对同批其他输入的梯度范数 | 0.466478 | 0 |

三处修正后三阶段链“单独/成批”差约 `2.38e-7`。这些是**实现正确性测量，不是检测 AUC**。本机与服务器源文件仅行尾字节不同，标准化换行后内容完全一致。

## 5. 后续优先级与可验证思路

### 优先级一：把独立基线与互补性补齐

先审计 PDI 的真实训练/验证视频与 checkpoint 对应，使用完整原生头重放独立 ViT；另用源域训练独立 CLIP-only 读取器。同一图像配对预测、各自在未参与拟合的源域验证视频定阈值，再交给 `exp_1/analyze.py` 统计“ViT 错 CLIP 对”与“ViT 对 CLIP 错”。不能把源训练内分数当校准集，不能从完整融合 logits 冒充纯 ViT。

这一步存在救回机会，只支持进入可部署选择规则的验证；真实标签选择 oracle 不能当融合效果。

### 优先级二：保住原生检测函数，再学有限增量

建议候选形式 `s = s_V_native + r(V,C)`，先固定原生 V 路径，避免随机融合头先破坏已有能力。对 C/Bridge 分别设置独立辅助检测头，短暂单支预热，再联合训练融合；辅助损失用于保证该分支收到学习信号，**不保证互补或跨域泛化**。

残差幅度在源验证中选择，包含 `r=0` 的确切退回基线；不根据目标集挑 alpha。不要同时把末层权重与唯一门控都置零，避免残差支路所有梯度被一起截断。若用零末层初始化，应记录前几步梯度预期，再判断是否真的饥饿。

这与旧残差探针的区别应明确为“保留原生头与训练监督方式”，不能宣称“残差思想首次尝试”或预设会成功。

### 优先级三：只有正确桥才值得投入训练

先通过样本隔离、batch 换位、梯度流、输入内容敏感性；再比较：原生 V、重新训练的 V-only 头、全局 V+C、正确 Bridge。采用同源划分、同选参预算、三 seed；给融合增加 V-only 同容量与噪声重训控制。修正注意力后复杂度从沿 batch 的 `O(S B²)` 变为真正沿序列的 `O(B S²)`，**旧吞吐与显存估算不再适用**，需重新做极小批量标定。

确认读取真实 C 还需同标签异视频 donor 与异标签对照，并审计真实视频身份；旧 `video_id` 可能是人物或帧号。主宏平均固定 CD2/DFDCP/Wild，报告配对区间与救回/误伤；不能只用训练 loss、alpha 或头权重作成功标准。

本次没有启动训练或 AUC 评测。先用结构核查消除无效试验条件，再决定训练预算。
