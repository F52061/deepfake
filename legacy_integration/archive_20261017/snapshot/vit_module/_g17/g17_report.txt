CAVEATS (honest)
  1. n=300 per target domain, 5-fold CV fold-to-fold variance large: single-domain AUC differences
     < ~0.04 should NOT be over-read; only cross-domain consistent directions + magnitude count.
  2. dfdcp is the ONLY fully clean held-out domain. cd2 has 28% images sharing cd1 videos,
     wild has 3% sharing probe-train videos -> both labelled SUB-CLEAN. cd1 is same-source as cd2
     (41/41 video overlap) -> NOT a held-out domain (reference only). ffiw = 1 video -> excluded.
  3. Aggregates use decision domains only: 'dfdcp' and 'dfdcp+cd2+wild'. cd1/ffiw never aggregated.
  4. F_all is built as F1|F1_radial|F2|F3|F4|F5 = 123-d to match the spec '123 dims, no F3_hist'.
     The spec text also wrote 'concat(F1,F2,F3,F4,F5)' which is 91-d; F1_radial is a SUBSET of F1
     (F1[:, :32]), so the 123-d version duplicates 32 dims. This is flagged; a 91-d alternative would
     drop the redundant F1_radial. All per-column standardization makes the duplication harmless to LR.
  5. C_proj for the 2300 multi rows is derived offline as F[:,0:768]/alpha_v (alpha_v=0.306288,
     G12 verified F[:,0:768]=alpha_v*C_proj with cos_min=1.000000); no checkpoint read, zero forward.
     StandardScaler is per-column so any uniform global scale on a block is exactly cancelled.
  6. G17_ORTHOGONAL gate (|cos(dV,e0)|) is structurally arm-invariant: for raw concatenation the
     V-subspace part of the joint class-mean-diff equals V's own class-mean-diff (cos~0.94-0.98).
     Hence it mechanically returns REDUNDANT for every arm; the informative orthogonality metric is
     C2's energy-outside-V fraction (||dF||^2/||delta_joint||^2).
  7. Capacity controls randn(K)/V@R control for 'adding K dims' vs 'adding real information'.
     'beats controls' = gain(dfdcp) > max(control gains over 3 seeds) + 0.01. With only 3 seeds the
     control range is a lower bound on its variance; borderline cases are labelled explicitly.
  8. Cross-domain AUC trains a LINEAR head on the source only -> lower bound on transferability;
     oracle trains in-domain -> upper-bound-ish (label-dependent, not deployable). Correlation !=
     causation: a [V|feat] gain shows the feat carries linearly-available signal V lacks, NOT that
     the detector would exploit it.
  9. Oracle 'best-of-4' reproduces G14 oracle_V mean4=0.9111 within tolerance (see A).
  10. All feature/CNN/freq rows were produced by G17a/G17b and are element-wise aligned with
     probe_feats / feats_multi row order (verified here too via y/vids).
