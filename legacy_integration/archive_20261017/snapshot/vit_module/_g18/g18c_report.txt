H. DEVIATIONS FROM G17c
------------------------------------------------------------------------------------------------------------------------------
  1. ARMS: only the 7 G18 arms + V baseline are evaluated (G17c evaluated 16 freq/CNN feats).
     The code path for each arm is byte-identical (same functions, same constants).
  2. SEEDS: G17c used control seeds [0,1,2]; here the control seed list is extended to
     [0,1,2,3,4] (>=5 as required) and the same list is used as the LR random_state.  Because
     lbfgs ignores random_state the arm dAUC is EXACTLY seed-invariant (std=0, per-seed list
     printed).  The G17c 3-seed control maximum is reported alongside (ctrl_max3) and the gate
     verdict under the G17c-exact 3-seed controls is printed as a variant.  The 5-seed max is
     the stricter (larger) bound, so the primary verdict uses it.
  3. Control matrices depend only on K, so they are built once per unique K (K in {512,1024})
     instead of per arm.  Same rng, same seed base, same construction -> identical numbers.
  4. ADDED (not in G17c): paired row-bootstrap std of dAUC on the target rows (B=2000) to give a
     real uncertainty scale, since the deterministic protocol yields std=0 over head seeds.
  5. ADDED (not in G17c): feat-alone cross-domain AUC, per-seed dAUC listing, G18a/G18b ratio
     recomputation.  None of these change the pre-registered quantities.
  6. ffiw is never aggregated (1 video).  VALID4 = cd1,cd2,dfdcp,wild is used for the
     G18_INCREMENT '3/4 valid domains' rule; the decision-domain variant (dfdcp,cd2,wild) is
     reported too.  cd1 is a valid transfer target for the probe-trained head (0 video overlap
     with probe-train) but is the same source family as cd2, so it is flagged not dropped.
