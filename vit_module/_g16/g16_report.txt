CAVEATS (honest)
  1. HOOK SEMANTICS UNCERTAINTY: the intermediate-layer features are the block-output residual stream
     (post-LayerNorm in the pre-norm sense, but NOT passed through the final vit.norm that V gets).
     We take them AS-IS from the registered hooks (the exact tensors the bridge consumes, minus its
     linear_vit_* projection). If a downstream comparison treats 'norm-before-vs-after' as material,
     the interpretation could shift; the block output is the un-normalized residual sum, not a unit-
     variance embedding.
  2. THE INTERMEDIATE FEATURES ARE NOT PASSED THROUGH the bridge's linear_vit_* (768->64) projections
     that the model actually fuses. This experiment therefore measures INFORMATION AVAILABILITY at each
     layer, NOT the model's actual learned fusion behaviour.
  3. n=300 per domain; 5-fold CV fold-to-fold variance is large (oracle stds reported in C3 tables via
     the per-method columns only at mean level -- see g14 for the same protocol). Single-domain AUC
     differences < ~0.05 should not be over-read.
  4. ffiw has exactly 1 vid -> StratifiedGroupKFold degenerates to StratifiedKFold (leak=True); its oracle
     is upward-biased and excluded from all aggregates (VALID_DOMAINS = cd1/cd2/dfdcp/wild).
  5. Concatenation standardization: StandardScaler is per-feature (mean/std per column), so a single fit on
     the concatenated vector is mathematically IDENTICAL to standardizing each 768-d block separately.
  6. Cross-domain AUC trains a LINEAR head on the source (FF++) domain only -> this is a LOWER BOUND on
     transferability ('linear reachability'); a non-linear or fine-tuned head could do better, and does
     not imply the fused detector would exploit the same signal.
  7. CORRELATION != CAUSATION: a higher cross-domain/oracle AUC for an intermediate layer shows that layer
     carries more linearly-available real/fake signal; it does not prove the detector uses it, nor that
     unfreezing/fine-tuning would convert it into a downstream gain.
  8. cls_final cross-domain anchors reproduced from fresh extraction (flash_attn MHA, as run_g10) match the
     G13 anchors (which were computed on feats_multi.npz extracted with the pure-PyTorch MHA shim) to
     <=1e-3, so no backend mismatch affects the verdicts at the reported precision.
  9. mp_* mean-pools the 196 patch tokens (CLS removed), discarding spatial layout; it is a coarse spatial
     summary, not the full patch set the bridge uses.
