# CLIP image 条件读取实验：从“可读信息”到“可用纠错”

> 2026-10-05 口径更正：本文件G26实现的`s_V=logits[:,0]-logits[:,1]`实际是完整融合检测器分数，已含CLIP image，不是纯ViT。既有产物保留，但不得据此计算“相对于纯ViT的增量”。新的纯ViT对照、同结构固定聚合和正确宏平均协议见`PURE_VIT_CLIP_EXPERIMENT.md`（G27），实现为`pure_vit_clip.py`。

## 1. 实验目的

前面的残差和局部实验已经证明：CLIP image 的局部表示不是随机噪声，但在静态拼接和线性读取下没有稳定超过 ViT CLS。本实验不再直接堆叠特征，而是验证一个更具体的结构假设：

> 保留 ViT 的主检测决策，只在样本级、区域级读取 CLIP image 的局部证据，并让该证据以受控的残差形式修正 ViT 分数。

本实验的目标不是追求最高 AUC，而是区分以下三种解释：

1. CLIP 局部信息确实能在 ViT 不可靠的样本上提供补充证据；
2. 所谓增益只是新增参数、非线性读取器或正则化带来的容量效应；
3. CLIP 特征虽可读，但不能稳定转化为检测纠错。

本实验只使用 CLIP image，不使用 CLIP text。

## 2. 预先注册的假设

### H1：补充信息假设

在保留 ViT CLS 的前提下，CLIP 局部区域特征仍包含可被源域训练读取的跨域判别信号。

### H2：条件读取假设

CLIP 补充证据不是对所有样本等权有用；根据 ViT 表示和当前区域内容自适应选择 CLIP 证据，比固定拼接或固定平均更能实现纠错。

### H3：样本对应假设

如果模型确实使用了当前图像的 CLIP 信息，把 CLIP 区域换成同域其他视频的区域或匹配噪声后，新增收益应明显下降。

H1 不成立时，不得用 H2 的失败来主张“门控设计不够好”。

### H4：域条件性假设

若 CLIP 局部信息只在部分目标域有效，原因应表现为同一读取器在不同域上的条件修正强度和方向不同，而不是简单的随机波动。具体预测为：

1. 真实当前图像的 CLIP 区域在某些域中能提高 `s_V` 的排序或纠错率；
2. 同域跨视频 donor 会破坏样本对应，跨域 donor 还会额外破坏 CLIP 与目标域的分布兼容性；
3. 逐域 `delta_auc`、`rescue_rate` 和 `harm_rate` 能解释哪些域有增益、哪些域没有增益；
4. 如果只有 cd1/cd2 有效，不能把它报告为两个独立域，因为 cd1 是 cd2 的子集。

H4 只用于解释增益异质性，不等同于证明 CLIP 学到了某一种固定的域标签捷径。

## 3. 第一阶段：冻结表征最小实验

第一阶段只训练轻量读取器，不更新 ViT、CLIP 或原模型分类头。输入来自：

- `V`：ViT 最后一层 CLS，维度 768；
- `C`：CLIP pooled image CLS；
- `C_i`：CLIP 最后一层九个相对位置区域，维度 1024；
- `s_V`：ViT-only 的固定伪造分数。主协议使用诊断管线的 `logits[:,0] - logits[:,1]`；若使用源域线性 V probe，必须另列为次要协议。

### 3.1 候选读取器

所有读取器使用相同的 FF++ 视频分组训练/验证划分、相同随机种子和相同训练预算。

| 编号 | 输入/结构 | 目的 |
|---|---|---|
| A | 固定 `s_V` | 原始 ViT 决策基线 |
| B | `V →` 小型非线性残差头 | 排除“非线性/新增容量”解释 |
| C | `V + C` 残差头 | 判断 pooled CLIP 是否足够 |
| D | `V + mean(C_i)` 残差头 | 固定区域聚合基线 |
| E | `V + [C_1,...,C_9]` 线性残差头 | 当前局部拼接的强基线，但保留 `V` |
| F | `V` 查询 `C_i` 的自适应区域读取器 | 预设的新结构 |

其中 B–F 都采用分数残差形式：

```text
s(x) = s_V(x) + delta(x)
```

`s_V` 在第一阶段固定。`delta` 是新增读取器预测的修正量，而不是重新学习一个完全独立的分类器。为防止读取器任意覆盖 ViT 决策，训练中加入小的修正量惩罚，并记录 `delta` 的均值、标准差和绝对值分位数。

统一目标函数为：

```text
L = BCEWithLogits(s_V + delta, y) + lambda_delta * mean(delta^2)
```

`lambda_delta` 只在 FF++ train 的视频分组验证中从预先固定的 `[0, 1e-4, 1e-3, 1e-2]` 选择；权重衰减只从 `[1e-4, 1e-3]` 选择。所有 `V`、`C` 和 `C_i` 的标准化统计只用 fit fold 估计，`C_i` 进入投影前沿用局部实验的逐区域 L2 归一化。不得根据目标域结果选择这两个网格。

### 3.2 F 结构定义

先将每个 `C_i` 投影到 `d=128` 或 `d=256`，再用 `V` 生成查询：

```text
q = Wq(LN(V))
k_i = Wk(LN(C_i))
v_i = Wv(LN(C_i))
a_i = softmax_i(q·k_i / sqrt(d))
u = sum_i a_i v_i
delta = h([LN(V), u, s_V])
s = s_V + delta
```

区域权重 `a_i` 只作为读取机制记录，不作为器官定位证据。固定网格仍然只是相对空间位置，不能命名为眼睛、嘴或边界。

为控制容量，F 的投影维度、隐藏层宽度和参数量应与 B–E 尽量接近。第一版只允许单头、单层区域聚合，不加入多层 transformer、额外 backbone 或目标域自适应。

## 4. 必须执行的控制实验

所有控制使用已经训练好的读取器，除“噪声重训”外不重新拟合参数。

### 4.1 关闭控制

令 `delta=0`，得到原始 `s_V`。关闭后性能下降的幅度必须与 F 的真实提升相对应，否则不能说收益来自修正分支。

### 4.2 ViT-only 容量控制

B 使用与 F 相近的参数量，但只输入 `V`。若 F 不能超过 B，说明提升更可能来自读取器容量，而非 CLIP。

### 4.3 CLIP pooled 控制

C 使用 `C` 而不是区域特征。若 F 不超过 C，局部自适应读取没有证据支持。

### 4.4 同域跨视频 CLIP 错配

保留当前样本的 `V` 和 `s_V`，将其九个 `C_i` 替换为同域、同 split、不同视频的区域。保存 donor 行号和视频号，禁止从同一视频取 donor，禁止跨 train/test。

该控制回答的是：F 是否依赖当前图像的 CLIP 内容，而不是 CLIP 区域的总体分布。

### 4.5 匹配噪声控制

生成与 FF++ train 的九区域均值/标准差匹配的噪声，执行两种版本：

1. 固定 F 权重，只替换测试输入；
2. 用噪声重新训练同结构读取器。

第一种检验输入依赖，第二种排除“同样容量就能得到收益”。

### 4.6 区域位置控制

只有在 F 使用显式区域位置编码时，才执行同一图像内的“区域—位置错配”。若 F 是无位置的集合聚合，区域顺序置换在数学上可能不改变输出，不得把它当作有效控制。

### 4.7 跨域 donor 控制

脚本还生成 `F_cross_domain`：保持当前样本的 `V` 和 `s_V`，将 CLIP 区域替换为**不同 domain、相同 split、不同 video** 的 donor。FF++ train 只有一个 source domain，因此 source train 行没有可用跨域 donor；这些行只能回退到原区域并记录为不可用，不参与跨域 donor 的证据。目标 test 域之间可以执行该控制。

解释顺序固定为：

| 结果 | 含义 |
|---|---|
| 真实 F 优于 A，同域 donor 退化 | 依赖当前图像的 CLIP 内容 |
| 跨域 donor 比同域 donor 进一步退化 | 存在域兼容性/域条件性迹象 |
| 同域和跨域 donor 都接近 A | F 的收益不依赖 CLIP 样本对应，需怀疑容量或边缘统计 |
| 只有一个域的真实 F 优于 A | 只能记为域条件现象，不能称稳定跨域互补 |

跨域 donor 是破坏性控制，不单独证明“目标域语义更好”；必须和真实 F、同域 donor、匹配噪声一起报告。

## 5. 数据划分与训练纪律

1. 只使用 FF++ train 拟合读取器、选择正则化、选择训练轮数和早停点。
2. FF++ train 内部按 `video_id` 做分组交叉验证；关联真实视频与其派生伪造视频时，必须保持在同一组。
3. 目标域标签只在最终评估时使用，不得参与结构、阈值、超参数或 donor 选择。
4. 使用至少 3 个固定种子，例如 `20261004/20261005/20261006`；各组必须共享种子和划分。
5. `cd1`、`cd2` 不作为两份独立重复证据；`ffiw` 只有一个视频，继续排除主聚合。
6. 目标域结果优先使用预先固定的新视频留出集；现有 300 张结果只能作为探索性复核。

## 6. 评估指标与预先判定

每个域同时保存：总体 AUC、相对 A 的视频分组 paired bootstrap 区间、相对 E 的区间、固定 ViT 错误集合的 rescue/harm、净救回、预测翻转率、`delta` 与区域权重统计。

脚本在 `summary.json` 的每个域下新增 `correction_diagnostics`，至少包括：

- `delta_auc`：修正量 `delta = s_F - s_V` 单独区分真假能力；
- `candidate_auc` / `baseline_auc`：该域的 F 与 A AUC；
- `rescue_rate`、`harm_rate`、`net_correction_rate`：以固定 `s_V=0` 阈值计算；
- `delta_mean`、`delta_std`、`delta_abs_p50`、`delta_abs_p90`：修正幅度和稳定性。

这些指标只能作为逐域机制描述，不能替代总体 AUC 的配对 bootstrap。

### 6.1 支持“CLIP 被使用”的证据链

以下条件需要同时满足，才可声称 F 真正利用了 CLIP image：

1. F 相对 A 的平均跨域差异为正，并在视频分组区间中排除 0；
2. F 相对 B 的差异仍为正，排除纯容量/非线性解释；
3. CLIP 跨视频错配或匹配噪声后，新增差异明显下降；
4. 至少多数目标域的 rescue-harm 为正，且不能由单一域贡献全部结果；
5. 三个训练种子方向一致。

若 F 只超过 A 而不超过 B，只能记为“读取器增强”；若错配后仍保留收益，不能证明使用了当前图像的 CLIP 证据。

### 6.2 支持“自适应读取优于简单融合”的证据

只有 F 同时超过 D/E，并且其相对噪声和错配的差异仍存在，才支持 H2。否则结论应限制为“CLIP 局部特征可被某种非线性读取”，不能归因于区域自适应。

### 6.3 失败判定

- F 不超过 A：当前 CLIP 局部信息不足以改善检测；停止架构扩展。
- F 超过 A 但不超过 B：收益主要是容量或非线性读取；不称为 CLIP 互补。
- F 超过 A/B，但错配和噪声仍接近真实 F：无法证明使用了样本对应的 CLIP 信息。
- 仅单一目标域有效，或 rescue 增加但 harm 更大：记录为域条件现象，不作为通用结构结论。
- 真实 F 只在 cd1/cd2 有效：合并解释为 Celeb-DF 现象，并明确 cd1 ⊂ cd2；不得计作两个独立成功域。
- 跨域 donor 比同域 donor 更差：可支持“域兼容性参与了 CLIP 读取”，但不能直接命名为域语义或域捷径。

## 7. 结果保存要求

建议输出到 `vit_module/_g26/conditional_clip_run01/`，目录不得预先存在。必须保留：

- `config.json`：代码、输入 config/checkpoint hash、种子、分组划分、超参数和标签口径；
- `split.json`：每个源域视频的 fit/validation 分组及行号；
- `features.npz`：样本身份、`V`、`C`、`C_i`、`s_V`；
- `scores.npz`：A–F 和全部控制的逐样本分数；
- `controls.npz`：donor 行号/视频号、噪声特征、区域错配索引；
- `adapter_*.pt` 或 `reader_*.npz`：每个种子和实验组的参数；
- `summary.json`：逐域及 mean4 指标、paired bootstrap、rescue/harm；
- `COMPLETE`：只有所有分组、种子和统计完成后才生成。

正式运行前先用少量 manifest 验证形状、标签方向、donor 不跨视频、关闭 `delta` 可精确恢复 `s_V`。任何失败的运行目录必须保留并在 `config.json` 中标记失败原因，不覆盖重跑。

## 8. 第二阶段：接入原架构的条件门控

只有第一阶段支持 H1/H2 后才做第二阶段。第二阶段将 F 的读取器改写为模型内的轻量 adapter：ViT 和 CLIP 编码器先冻结，只训练区域投影、查询/键值模块和残差头；确认有效后，再进行有限解冻实验。

第二阶段仍保留同样的 A–F、错配、噪声和关闭控制。不能因为端到端训练获得 AUC 提升，就跳过第一阶段的容量和输入依赖证据。

## 9. 可写入报告的结论边界

本实验成功后，允许的最强表述是：

> 在冻结 ViT 主检测表示的条件下，样本级/区域级读取器能够利用 CLIP image 的局部信息，对部分 ViT 错误样本进行跨域条件修正；该修正不能由同等容量的 ViT-only 读取器或匹配噪声完全复现。

若控制链不完整，只能写：

> CLIP image 局部特征具有可读性，但当前实验尚未证明其相对于 ViT 的稳定条件互补性。

不得写成“CLIP image 一定学习到了 ViT 完全没有的真伪因素”，也不得把区域权重解释为器官语义。
